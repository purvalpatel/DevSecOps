#subfinder
Sub domain finder. <br>
Reference: https://github.com/projectdiscovery/subfinder <br>

### How to download:
1. Install go language package:
```
sudo apt-get install golang-go
go install -v github.com/projectdiscovery/subfinder/v2/cmd/subfinder@latest
```
2. Package compiled at `go/bin/subfinder`


### How to use:
```
cd go/bin/
./subfinder -d domain.com -v
```
